# Expression Picker for [Monika After Story](https://github.com/Monika-After-Story/MonikaModDev)
Just an expression picker for Monika After Story.

It's an HTML file so it can be ran in a web browser totally fine.

IT'S ALL VIBE CODED WITH CLAUDE AI

## Features ##

- Importable Monika Sprites (if you have edited sprites in ```/game/mod_assets/monika```, you can preview your own assets :D!)
- A dialogue builder, you can chose your expression and it will automatically added to your custom sentence. Then you can copy and paste as a part of your code.
- Quick expression picker that are frequently used.
- A random expression button... because why not?
- A expression decoder, to take a peek at a already made reaction
